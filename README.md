# Проект по работе с вакансиями с hh.ru

## Описание проекта

Данный проект предназначен для получения информации о компаниях и их вакансиях с платформы hh.ru. Используя публичный API hh.ru, проект позволяет получить данные о работодателях и вакансиях, сохранить их в базу данных PostgreSQL и предоставить функциональность для работы с этими данными через класс `DBManager`.

## Функционал

- Получение информации о работодателях и вакансиях с hh.ru.
- Загрузка данных в базу данных PostgreSQL.
- Методы для работы с базой данных, включая:
  - Получение списка всех компаний и количества вакансий у каждой компании.
  - Получение списка всех вакансий с информацией о зарплате и ссылке.
  - Вычисление средней зарплаты по всем вакансиям.
  - Получение вакансий с зарплатой выше средней.
  - Поиск вакансий по ключевым словам в названии.

## Принципы разработки
- В проекте соблюдены основные принципы SOLID (минимум для первых двух).
- Все классы и методы задокументированы.
- Все методы классов имеют типизацию.
- Все коммиты выполняются без игнорируемых файлов, и проект не нарушает PEP 8.
